**Чат-бот для образовательных мероприятий компании**

Чат-бот предназначен для информирования сотрудников о предстоящих лекциях и CrossTalks, а также для сбора идей для новых лекций.

Функциональность:
1. Уведомления о мероприятиях:
   • Сотрудники получают уведомления о готовящихся лекциях и CrossTalks (квартальное мероприятие со спикерами).
   • Уведомления отправляются автоматически:
     • За неделю до мероприятия
     • За 3 дня до мероприятия
     • Утром в день мероприятия
     • За 5 минут до начала мероприятия
2. Администраторские функции:
   • Администраторы могут программировать рассылку уведомлений.
   • Данные о предстоящих мероприятиях переносятся из Google Sheets с помощью Google APIs.
3. Персонализированное взаимодействие:
   • Бот приветствует сотрудников по имени.
   • Проверяет, является ли пользователь сотрудником, чтобы защитить конфиденциальную информацию от посторонних.
4. Обратная связь и заявки:
   • После мероприятий сотрудники могут оставить обратную связь с использованием Google Forms.
   • Сотрудники могут отправлять заявки на проведение лекций через Google Forms, ссылки на которые можно получить в дайджесте через чат-бота.
